# 00 — 概要・目的・完成条件

## これは何か

**Akari（灯り）** は、手元で動かしているローカルLLMを日常的に使うためのデスクトップアプリと、
同じ中核を使うコード作業用CLIの組。

- **対象の利用者**: オーナー1人（個人用ツール）。
- **解決する問題**: ローカルLLMサーバ（Ollama / llama.cpp server / LM Studio / vLLM 等）を立てても、
  実際に使う入口が `curl` かブラウザの素朴なUIしかない。会話の保存、作業単位のまとめ、
  ファイルを触らせる作業、コード編集が、それぞれ別のツールに散っている。
- **やること**: OpenAI互換APIを話す相手なら何にでも繋がる1つのアプリで、
  「会話する」「作業をまとめる」「エージェントに手を動かさせる」「コードを書かせる」を扱う。
  同じ中核ロジックを、ターミナルから使うCLIとして出す。

## 非目標（作らないもの）

明示的に作らない。これを作りたくなったら、まず仕様を更新して承認を取る。

- モデルのダウンロード・量子化・サーバ起動の管理。Ollama 等に任せ、Akari は接続するだけ。
- 独自の推論エンジン。llama.cpp 等を直接組み込まない。
- マルチユーザー、アカウント、クラウド同期、チーム共有。
- プラグイン機構、拡張API、テーマストア。
- モバイル対応、Web版、ブラウザ拡張。
- RAG基盤（ベクトルDB、埋め込みインデックス）。将来の候補ではあるが v1 には入れない。
- 音声入出力。

## 完成条件

外から見て確かめられる形で書く。すべて満たしたときに v1 完成とする。

### 接続
- [ ] 設定画面でベースURL（例 `http://localhost:11434/v1`）を入れると、`/models` から取得したモデル一覧が出る。
- [ ] 接続できないとき、原因（到達不可 / 認証 / 応答が非互換）が区別して表示され、対処が書いてある。
- [ ] 接続先を複数登録し、切り替えられる。

### Chat
- [ ] 新しい会話を作り、送信すると応答がトークン単位で流れて表示される。
- [ ] 生成中に停止でき、そこまでの内容が会話に残る。
- [ ] アプリを再起動しても、会話一覧と各会話の内容が残っている。
- [ ] 自分の発言を編集して再送すると、以降が作り直され、元の枝も辿れる。
- [ ] コードブロックがハイライトされ、1クリックでコピーできる。

### Work（プロジェクト）
- [ ] プロジェクトを作り、専用の指示・既定モデル・作業フォルダ・資料ファイルを設定できる。
- [ ] プロジェクト内で始めた会話は、その設定を引き継いだ状態で始まる。
- [ ] プロジェクトに属する会話が、そのプロジェクトの画面に一覧される。

### Work（エージェント実行）
- [ ] 目的を1つ書いて実行すると、ツールを使いながら複数ステップ進み、各ステップが時系列で見える。
- [ ] ファイル書き込みとコマンド実行の前に承認を求め、拒否すると実行されない。
- [ ] 作業フォルダの外を読み書きしようとした場合は、承認以前に拒否される。
- [ ] 実行後に「元に戻す」で、その実行が行ったファイル変更を戻せる。
- [ ] 実行中に停止でき、停止時点までの変更と経過が残る。

### Code
- [ ] 作業ディレクトリを開くと、ファイルツリーと、その中身をエージェントが読める状態になる。
- [ ] 提案された変更が before/after の差分として見え、適用・却下を選べる。
- [ ] コマンド実行の出力（標準出力・標準エラー・終了コード）が読める形で残る。
- [ ] git リポジトリなら、変更後に `git diff` 相当の差分が画面から確認できる。

### CLI
- [ ] `akari "このリポジトリのテストを通して"` をリポジトリ直下で実行すると、デスクトップ版と同じ挙動でエージェントが動く。
- [ ] `akari chat` でツールなしの対話ができる。
- [ ] `akari --json` で1行1イベントの機械可読な出力が得られる。
- [ ] `akari undo` で直前の実行のファイル変更が戻る。
- [ ] `akari doctor` が接続先・モデル・機能対応状況・設定の要約を出す。

### 運用
- [ ] Windows / macOS / Linux でインストーラまたは実行可能な配布物ができる。
- [ ] 「問題報告用の書き出し」1コマンドで、バージョン・設定要約（秘密は伏せる）・直近のログがまとまったファイルが出る。
- [ ] 保存データの場所と形式がドキュメントに書かれており、手で読める。

## 用語

| 語 | 意味 |
|---|---|
| **接続先（Endpoint）** | OpenAI互換APIを話すサーバ1つ分の設定。ベースURL、鍵、既定モデル、対応機能。 |
| **会話（Conversation）** | メッセージの列。1つのファイルに保存される。 |
| **プロジェクト（Project）** | 作業単位。専用指示・既定設定・作業フォルダ・資料・会話をまとめる。 |
| **実行（Run）** | エージェントが目的を受けて、停止または完了するまで回る1回分。 |
| **ステップ（Step）** | 1回のモデル呼び出しと、それに続くツール実行。 |
| **ツール（Tool）** | モデルが呼べる関数。ファイル読み書き、検索、コマンド実行など。 |
| **作業フォルダ（Workspace）** | ツールが触ってよい唯一の範囲。この外は拒否される。 |
| **変更記録（Change Journal）** | 実行がファイルへ行った変更の記録。差分表示と取り消しの根拠。 |
