# 08 — UI 仕様

正本: `context/personal/ui.md`。ここはそれをこのプロジェクトへ落とした結果だけを書く。

## 系統

**現代的な角丸UI**を採る。理由は、参考として挙がったのが Claude デスクトップアプリであること。
古い四角いUIは採らない。混ぜない。

ただし `ui.style` に `classic`（Windows 98 風）を用意する余地を残す。
v1 では `modern` のみ実装し、`classic` は設定に出さない。**未使用の切り替えを画面へ出さない。**

## 色

役割を先に決め、色を後で当てる。3系統すべては使わない。

| 役割 | 色系統 | ライト | ダーク |
|---|---|---|---|
| 主要操作・強調・現在位置 | オレンジ系（灯り） | `#C8702A` | `#E0904A` |
| 情報・リンク・選択中の面 | 水色系 | `#3F7C94` | `#6BA8BE` |
| 成功・追加行 | 黄緑系 | `#5F8A3C` | `#8DBA63` |
| 警告 | 黄橙系 | `#B0761A` | `#D9A241` |
| 危険・削除行・失敗 | 赤系（役割上必要） | `#B04A3C` | `#D4796A` |
| 背景 | 無彩 | `#FBFAF8` | `#17181A` |
| 面（カード・サイドバー） | 無彩 | `#FFFFFF` / `#F2F0EC` | `#202225` / `#1B1C1E` |
| 本文 | 無彩 | `#22242A` | `#E6E4E0` |
| 補助文字 | 無彩 | `#6B6E76` | `#9A9CA2` |

- 高彩度を避ける。上の値は暫定。実装後に実機のコントラストを測って調整する。
- 文字と背景のコントラストは 4.5:1 以上を満たす。色だけで意味を示さない
  （差分は `+` / `-` の記号も付ける。エラーはアイコンと文言も付ける）。
- 色付きの面に不透明度80%を使うのは、選択中の行と、承認待ちの枠に限る。全面には使わない。

## 寸法（暫定・プロジェクトの正本はここ）

| 項目 | 値 |
|---|---|
| 余白スケール | 4px 基準（4 / 8 / 12 / 16 / 24 / 32） |
| 角丸 | 小（ボタン・入力）6px、面（カード・吹き出し）10px、モーダル 14px |
| 本文 | 14px / 行間 1.6 |
| 補助・メタ | 12px |
| 見出し | 16px / 20px |
| 等幅（コード・差分・ログ） | 13px / 行間 1.5 |
| 書体 | システムUIフォント。日本語は OS 標準（Windows: Yu Gothic UI / macOS: Hiragino Sans / Linux: Noto Sans CJK JP）。等幅は各OS標準 |
| 最小ウィンドウ幅 | 900px。それ未満では右ペインを畳む |

すべて暫定。実際に使ってみて調整する前提で、CSS 変数1箇所にまとめる。

## 画面構成

左サイドバー（固定 240px、折りたたみ可）+ 主領域。上部タブは使わない
（画面の種類が3つしかなく、サイドバーで足りるため）。

```
サイドバー
  [新しい会話]                 ← 主要操作。文字付きボタン
  検索 ▢
  ▾ チャット
      ・最近の会話（20件、無限スクロール）
  ▾ プロジェクト
      ・プロジェクト名（会話数）
  ▾ コード
      ・最近開いた作業フォルダ
  ─────────
  接続先: ローカル (Ollama) ●   ← 状態ランプ。押すと切替
  設定
```

- 現在位置は、背景（水色系80%）と左端4pxの帯（オレンジ）で示す。
- 接続先の状態ランプ: 緑=応答あり / 灰=未確認 / 赤=到達不可。
  30秒ごとではなく、**操作の直前と、失敗したときだけ**確認する。待機時に定期通信しない。

## 情報密度

`density` で2段階。既定は `comfortable`。
`compact` は行の高さと余白を約25%詰める。文字サイズは変えない（読めなくなるため）。

会話一覧のように件数が多い場所は密度を上げる。会話本文は下げる。
「少ないほど現代的」とは扱わない。

## 遊び心

主要操作・状態・エラーの分かりやすさを損なわない範囲で。

- 空の会話一覧: 「まだ何もありません。」+ `[新しい会話]` のみ。イラストや長い説明を置かない。
- 生成待ちの表示は、脈打つ小さな灯りのアイコン（アプリ名に合わせる）。
  ただし待ち時間の秒数を必ず併記する。アニメーションで待機を曖昧にしない。
- 実行が完了したときの控えめな反応（アイコンが一瞬明るくなる、200ms）。
  失敗通知より目立たせない。
- ステップのタイムラインで、ツールごとに小さなアイコン。文字ラベルも必ず併記する。

## アニメーション

- サイドバーの開閉 150ms、モーダル 120ms、それ以外は原則なし。
- `prefers-reduced-motion` を尊重し、有効なら全部止める（状態変化は即時に切り替える）。
- 進行中を表す表示は、実際の進捗が取れないときに**割合を出さない**。
  ステップ数（3/25）のように、実測できる数だけを出す。

## キーボード

| 操作 | Windows/Linux | macOS |
|---|---|---|
| 送信 | `Enter` | `Enter` |
| 改行 | `Shift+Enter` | `Shift+Enter` |
| 新しい会話 | `Ctrl+N` | `Cmd+N` |
| 検索 | `Ctrl+K` | `Cmd+K` |
| 停止 | `Esc` | `Esc` |
| 承認 / 拒否 | `Y` / `N`（承認ダイアログに焦点があるとき） | 同じ |
| サイドバー開閉 | `Ctrl+B` | `Cmd+B` |

すべての対話要素に焦点表示（2px のオレンジ枠）を出す。タブ順は視覚順と一致させる。

## 破壊的操作の見せ方

| 操作 | 確認の強さ |
|---|---|
| メッセージの削除（子孫あり） | 件数を示す確認ダイアログ |
| 会話・プロジェクトの削除 | 確認ダイアログ。「ゴミ箱へ移動」と明記 |
| ゴミ箱を空にする | 件数を示し、`削除` の文字入力を求める |
| エージェントのファイル書き込み | 差分プレビュー付き承認（`06`） |
| コマンド実行 | コマンド全文と作業ディレクトリを表示した承認 |
| `full` モードの有効化 | 何が自動になるかの一覧 + 明示的な同意 |
| 設定の初期化 | 確認ダイアログ + 現在の設定の書き出しを提案 |

日常的で戻せる操作（会話の切替、表示設定の変更）には確認を出さない。

## 未定のまま残すもの

アイコンセット（暫定でLucide相当の線アイコン）、アプリのロゴ・イラスト、
正式なアクセシビリティ適合水準（暫定で WCAG 2.1 AA のコントラストのみ満たす）。
必要になった時点で決める。
