# Log

上から新しい順、または追記順のどちらでもよい。整えることより、書き続けられることを優先する。

## 記録のひな形

```
## YYYY-MM-DD — 一言で言うと何が起きたか

- 作業:
- 観察（事実だけ）:
- うまくいったこと:
- 失敗した・不満だったこと:
- 影響の大きさ:
- 分類の候補: Generic / Personal / プロジェクト固有 / 今回限り
- 証拠（ログ、差分、画面など）:
- 対応: 様子見 / ルール化する / 却下
```

## ルール変更の記録

```
## YYYY-MM-DD — ルール変更

- 変更したファイル:
- 変えた内容:
- 根拠になった記録:
- 既存のエージェントの挙動が変わる場合の注意:
```
