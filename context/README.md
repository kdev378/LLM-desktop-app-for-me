# context/

AIエージェント向けの開発ルール一式。入口はリポジトリ直下の `AGENTS.md`。ここを直接読み始めない。

## 構成

| 場所 | 中身 | いつ読むか |
|---|---|---|
| `core.md` | 常時適用の基本ルール | 毎回 |
| `generic/` | 誰にでも当てはまる技術上の既定。10ファイル | 該当する作業のときだけ |
| `personal/` | オーナー固有の好み。generic と異なる部分だけ | `working-with-me.md` は毎回、他は該当時 |
| `.claude/skills/`（context の外） | 手順の型 | 該当する作業のときだけ |
| `lifecycle/` | このルール集自体を育てる記録 | 不満や繰り返しの失敗が出たとき |
| `PROJECT-CONTEXT.template.md` | プロジェクト側に置く雛形 | 新しいプロジェクトを始めるとき |

## 保守のルール

- 1つの事実・ルールの正本は1ファイル。他所からは参照でつなぐ。複製した瞬間に食い違い始める。
- `personal/` に generic と同じ内容を書かない。**異なるとき**だけ書き、意図的な例外だとわかるようにする。
- `MUST` を増やすときは慎重に。全部が必須なら、優先順位は存在しないのと同じ。
- 追加するときは、既存ファイルへの数行の追記を第一候補にする。新規ファイルは、既存のどれにも属さないときだけ。
- プロジェクト固有の事実（コマンド、構成、ドメイン規則、完成条件）はここに入れない。`PROJECT-CONTEXT.md` に入れる。

## 分量の目安

常時読ませるのは `core.md` + `personal/working-with-me.md` の約7KB。
これが膨らみ始めたら、増やす前に何を削るかを決める。
